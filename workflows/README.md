# Workflows

Markdown SOPs that define how to accomplish specific tasks.

Each workflow should include:
- **Objective** — what this workflow achieves
- **Inputs** — what the agent needs before starting
- **Steps** — ordered instructions referencing specific tools
- **Outputs** — what success looks like and where results go
- **Edge cases** — known failure modes and how to handle them

Workflows evolve as the system learns. Update them when you discover better methods,
new constraints, or recurring issues.
